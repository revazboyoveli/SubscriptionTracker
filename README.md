# Subscription Tracker

**Subscription Tracker** is a Windows program made with C++ and Qt, which helps you track your subs.

## Features
**Manage Your Subscriptions:** Add, edit, or delete them.
**Manage Your Spendings:** automatically calculates total spending.
**Save the data:** information is being saved locally.
**Convenient GUI:** clean interface.

## Programs I used
**Language:** C++
**GUI:** Qt
**IDE:** Visual Studio

## How to Run
Go to the **release** section.
Download 'SubscriptionApp.zip.'
Unzip the folder and run the 'SubscriptionTrackerGUI.exe' (downloading Visual Studio or Qt is not necessary).
